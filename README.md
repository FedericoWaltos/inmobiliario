# Índice Federal del m² — prototipo

Dashboard demostrativo para comparar el precio de publicación residencial por m² entre:
- Mercado abierto: ZonaProp + Argenprop (a deduplicar en producción)
- +Hogares BNA

## Publicarlo y obtener una URL
1. Crear un repositorio nuevo en GitHub.
2. Subir `app.py` y `requirements.txt`.
3. Entrar a Streamlit Community Cloud y elegir **Create app**.
4. Conectar GitHub, seleccionar el repositorio y `app.py`.
5. Pulsar **Deploy**. Streamlit generará una URL web para abrir el dashboard.

> Los datos incluidos en este prototipo son sintéticos y están rotulados como demostrativos. Deben reemplazarse por el relevamiento real validado antes de usar el tablero para informes internos.
